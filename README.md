# Portafolio Personal - Eduardo Alvarado

Portafolio web personal desarrollado con HTML5, CSS3 y JavaScript para presentar mi perfil profesional, proyectos destacados, habilidades técnicas y experiencia académica.

## Descripción

Este proyecto consiste en una landing page moderna y responsiva que funciona como carta de presentación profesional. Incluye secciones de presentación, sobre mí, habilidades, proyectos, design system y contacto.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git y GitHub
- GitHub Pages

## Características

- Diseño responsive para desktop, tablet y móvil
- Navegación funcional entre secciones
- Menú hamburguesa para dispositivos móviles
- Modo claro y oscuro
- Sección de proyectos con cards reutilizables
- Diseño consistente con CSS variables
- Sección de componentes y estilo visual (Design System)
- Validación del formulario de contacto
- Favicon personalizado

## Cómo visualizar el proyecto localmente

1. Clona el repositorio:

```bash
git clone <url-del-repositorio>
```

2. Abre la carpeta del proyecto.

3. Puedes abrir `index.html` directamente en el navegador o iniciar un servidor local, por ejemplo:

```bash
python -m http.server 8000
```

4. Luego visita:

```text
http://localhost:8000/
```
